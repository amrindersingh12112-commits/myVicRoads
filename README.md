# myVicRoad Demo — Web App

## What this is
A static, mobile-friendly Progressive Web App (PWA) using fictional demo data. It is independent and not affiliated with VicRoads or the Victorian Government.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `roadmate-demo`.
2. Upload every file from this folder to the repository root.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. Open the published URL GitHub gives you.

## Add to iPhone Home Screen
Open the live website in Safari → Share → Add to Home Screen → enable **Open as Web App** if shown → Add.

Do not present this as an official VicRoads or Victorian Government app. Use your own branding and fictional data.
